# Planner Studio

Gumawa ng sarili mong printable planner. Pumili ng template, kulay, font at paper size, tapos i-download bilang PDF o i-print.

## Features
- Daily, Weekly, Monthly at Habit Tracker templates
- A4, A5 at US Letter
- 5 color themes at 3 fonts
- Lined, dotted, blank at checklist na linya
- Puwedeng i-edit ang mga heading sa mismong page
- Download PDF at Print

## Paano gamitin
Buksan ang `index.html` sa browser, o bisitahin ang live site.
